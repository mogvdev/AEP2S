# PSE em Ação — Sistema de Planejamento e Acompanhamento de Ações de Saúde na Escola

## Sobre o projeto

O PSE em Ação é um projeto acadêmico desenvolvido para a AEP do 2º semestre, do curso de Engenharia de Software da Unicesumar.

A ideia é criar um sistema simples, executado em terminal e desenvolvido em C, para organizar informações sobre ações de saúde realizadas nas escolas.

O sistema permitirá cadastrar ações, consultar os registros, atualizar seu andamento e visualizar um resumo das atividades.

## Funcionalidades

- Cadastro de ações.
- Listagem dos registros.
- Pesquisa por código, escola ou tema.
- Atualização da situação das ações.
- Registro da quantidade de participantes.
- Resumo geral das atividades.
