# PSE em Ação

Sistema de Planejamento e Acompanhamento de Ações de Saúde na Escola.

## Sobre o projeto

Projeto da AEP do 2º semestre de 2026, do curso de Engenharia de Software da Unicesumar.

A proposta é desenvolver um sistema em C, executado no terminal, para cadastrar e acompanhar ações do Programa Saúde na Escola.

## Funcionalidades

- Cadastrar ações
- Listar ações
- Pesquisar por código, escola ou tema
- Atualizar a situação das ações
- Registrar participantes
- Gerar um resumo geral
